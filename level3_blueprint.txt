# AI Project Context & Development Blueprint

## Project Overview

I am building my first serious AI application as a learning project. The primary objective is not to create the most feature-rich product, but to deeply understand how modern AI applications are architected so that I can build larger and more sophisticated AI systems in the future.

This project serves as the foundation for future AI projects, particularly larger-scale AI assistants and orchestration systems. My long-term goal is to eventually build an advanced AI project called SoulEcho, but this current project should prioritize strong architectural understanding over complexity.

I would like all guidance to emphasize understanding, scalability, maintainability, and professional software engineering practices rather than simply producing working code.

---

# Project Goal

The application is an AI-powered search assistant.

Users should be able to:

* Type a question into a search bar.
* Send that question to a backend API.
* The backend retrieves relevant context from a predefined knowledge source.
* The backend constructs an AI prompt.
* The AI generates an answer using only the provided context.
* The frontend displays the AI's response.

The project should mimic how internal company AI assistants or customer support assistants work.

The AI should not simply behave like ChatGPT. Instead, it should answer questions using company-specific information that I provide.

# Prompt Engineering Philosophy

The AI should not simply receive the user's message.

The backend should be responsible for constructing the final prompt.

Example workflow

User Question

↓

Intent Detection

↓

Relevant Context

↓

System Prompt

↓

Conversation History (future)

↓

Final Prompt

↓

LLM

This teaches prompt orchestration instead of simple prompting.
